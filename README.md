# Folded Keep

Defend a castle by folding the map it is drawn on. Drag an edge of the parchment,
then release to crush invaders with the towers printed on the other side.

Made for SlapJam AI #1, September 28–30, 2026. The jam build is published on itch.io.

## Run locally

Import `project.godot` in Godot 4.7.2 and press **F5**. The game uses the GL
Compatibility renderer and supports one mouse button or a finger. The web export
uses no threads.

See [DESIGN.md](DESIGN.md) for gameplay and architecture, and [TASKS.md](TASKS.md)
for the development history.
